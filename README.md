# woody-woodpacker

42 outer-core project — an x86_64 ELF packer, extended with 32-bit, Mach-O,
a parameterised key, LZSS compression and an asm-optimised decrypt loop.

## Learning
This is being built as a guided learning project. Start at
[`learn/00-PLAN.md`](learn/00-PLAN.md) for the overview, constraints and
section index. Progress and state live in `learn/PROGRESS.md`.
